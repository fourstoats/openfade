> AI agents for trading, scripting, and automation.

Openfade is an AI-native trading infrastructure project focused on making
specialized trading scripting accessible through natural language.

It combines language models with domain-specific documentation and retrieval
to generate reliable trading scripts for scripting environments that are not
well represented in general-purpose AI models.

### Scope
The initial development focuses on:

- **Lipi** — GoCharting's scripting language
- **Pine Script** — TradingView's scripting language

Openfade provides the context, retrieval, and agent workflows required to
translate trader intent into executable scripts.

### Architecture
The system is built around:

`Python` · `Go` · `LangChain` · `LangGraph` · `RAG` · `Vector DB` · `PostgreSQL`

### Development
Openfade is currently in its first development phase, focused on building
the core scripting generation infrastructure and agent workflows.
